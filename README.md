# Whale Radio (v1)
Static site, no server. Open index.html through any static host.
- stations.js: station metadata + credits
- audio/: 30-60 s loudness-normalized clips (see Credits in the page)
- narration/<lang>/<station id>.mp3 + scripts.json: Auntie CeCe intros. Add Twi as narration/tw/ and add `tw:'Twi'` to LANGS in stations.js.
